# 🛒 Shopping Cart - Client (Step 2)

React 기반 장바구니 클라이언트입니다. Step1 에서 구현한 장바구니 API 를 호출하여 상품을 조회하고,
상품 선택 / 수량 변경 / 삭제 등의 상호작용에 따라 결제 금액과 배송비를 동적으로 계산합니다.

<br/>

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 린트 검사
npm run lint
```

### 환경 변수

API 서버 주소는 환경 변수로 주입합니다. 프로젝트 루트에 `.env` 파일을 생성하세요.

```env
VITE_API_URL=http://localhost:3000
```

## 기능 요구 사항

- [x] 장바구니 API 를 호출하여 장바구니 상품 데이터를 불러온다.
- [x] 불러온 데이터를 기반으로 클라이언트 상태를 구성하고 관리한다.
- [x] 상품의 선택 여부, 결제 금액, 배송비 등의 상태를 관리한다.
- [x] 상품 선택 여부는 새로고침 시에도 유지되도록 한다. (`localStorage`)
- [x] 상품 선택에 따른 결제 금액, 배송비 등의 동적인 변경 사항을 처리한다.
- [x] 진입 시, 전체 선택 되어 있는 것이 디폴트이다.
- [x] 상품 선택 / 해제 시 결제 금액을 동적으로 변경한다.
- [x] 결제 금액이 10만원 이상일 경우 배송비는 무료이다.
- [x] 장바구니 상품의 수량을 변경할 수 있다. (최대 99개)
- [x] 장바구니에 담긴 상품을 제거할 수 있다.
- [x] 상품명은 최대 100자이다.

## 프로그래밍 요구사항

> 이전 미션의 프로그래밍 요구사항은 기본으로 포함한다.

### State Management

- React 상태 관리 훅(`useState`, `useReducer`)으로 상태를 구성하고, 필요 시 Context API 등을 활용해
  상태가 필요한 컴포넌트 트리에 전달한다.
- 결제 금액, 배송비 등은 별도 상태로 저장하지 않고 **파생 상태(Derived State)** 로 동적으로 계산한다.

### Data Fetching Hook

- 서버 API 통신 결과를 관리하는 함수를 직접 개발한다.
- 반환값에는 데이터, 로딩 여부, 에러 정보 등이 포함되어야 한다.
- 상용 라이브러리의 인터페이스를 모방하지 않고, 동작 메커니즘을 이해하고 직접 구현하는 데 집중한다.
  - "어떻게 SSOT 를 지켰을까?", "어떻게 캐싱을 할까?" 등을 고민한다.

### API

- Step1 에서 만든 API 를 그대로 적용한다.
- 비동기 작업(API 요청)의 상태를 관리하고, 상태에 따라 적절한 UI 를 보여준다.
  - 요청 중에는 로딩 UI(텍스트, 스피너, 스켈레톤 등)를 표시한다.
  - 요청 중 에러 발생 시, 에러 메시지를 사용자에게 알려주는 UI 를 표시한다.

### Test

- Jest, React Testing Library 로 주요 기능에 대한 테스트 케이스를 작성한다.
- 비동기가 포함된 테스트는 MSW 를 활용한다.
- 주요 기능을 명확히 정의하고, 어떻게 테스트할지 스스로 판단한다.

### 코드 퀄리티

- 컴포넌트와 비즈니스 로직을 분리하여 재사용 가능하게 한다.
- 컴포넌트 내에서 함수를 호출하는 방식과 props 로 받는 방식을 구별하고 더 나은 방법을 채택한다.
- 사용하기 좋은 인터페이스를 고민하고, 컴포넌트의 다양한 use case 를 떠올린다.
- `refetchCart`, `deleteCartItem` 처럼 세부 구현을 드러내는 props 는 안티 패턴이다.
  다른 use case 대응이 어렵기 때문이며, DIP 를 떠올려 추상화된 인터페이스를 설계한다.

### Library

- 스타일링은 CSS Module, styled-components, emotion 중 하나를 선택한다. → **Emotion** 사용
- 페이지 전환에 react-router 를 사용할 수 있다. (필수 아님) → 사용
- 학습한 라이브러리(msw, storybook)와 명시된 라이브러리 외에는 직접 구현한다.
